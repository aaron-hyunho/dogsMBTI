# 강아지 MBTI — 메가주 QR 테스트

별도 서버 없이 GitHub Pages(설문 화면) + Google Apps Script(응답 수신) + Google Sheets(저장)로 운영하는 모바일 웹앱입니다.

## 구현 기능
- 탐색 성향·활동 성향 2축(E↔C, S↔T) × 각 2문항 + 간식 식감·원료 선호 2문항, 총 6문항의 양극형 5점 척도 설문
- 시작 후 별도 화면에서 강아지 이름 입력 → 검사 시작 → 한 화면에 한 문항씩 진행
- 6문항 모두 1~5점 중 필수 선택하며, 이전 문항으로 돌아가 답변 수정 가능
- 화면 순서: 산책 탐색 → 간식 식감 → 집 활동 → 공간 탐색 → 간식 원료 → 산책 활동
- 4개 기본 성향 유형(ET/ES/CT/CS), 현장 간식 기록(7개 제품)
- 시식하지 않은 고객도 유형 카드 발급
- 인스타그램 스토리 비율(1080×1920) PNG 생성 및 휴대전화 공유 메뉴
- 구글시트 연결 시 결과 확인 후 응답 저장(저장 성공/실패 확인 메시지)
- 개인정보 최소화: 휴대전화/이메일/사진 수집 없음

> 재미로 알아보는 성향 콘텐츠이며 공식 MBTI 검사나 과학적으로 검증된 성격 진단이 아닙니다. 간식 선택은 성향 계산에 영향을 주지 않습니다. 3점 동점/정보부족은 임시로 E 또는 S에 배정하고 결과 페이지에 '불명확' 고지를 합니다. 운영 전 설문 검증 필요.

## 로컬 실행

최초 한 번 의존성을 설치한 뒤 개발 서버를 실행합니다.

```sh
npm install
npm run dev
```

브라우저에서 `http://localhost:1000`으로 접속합니다. 포트 `1000`이 이미 사용 중이면 서버가 오류를 표시하며 종료됩니다.

## 1. 구글시트 연결

1. 새 Google Sheets 문서를 생성합니다.
2. **확장 프로그램 → Apps Script**를 선택합니다.
3. `Code.gs` 파일의 내용을 그대로 붙여 넣고 저장합니다.
4. 함수 목록에서 `setupSheet`를 선택하고 **실행**합니다. 첫 실행은 구글 권한 승인이 필요합니다.
5. **배포 → 새 배포 → 웹 앱**에서 **다음 사용자 인증 정보로 실행: 나**, **액세스 권한: 모든 사용자**를 지정하고 배포합니다. (조직 정책상 허용되지 않을 수 있습니다.)
6. 발급되는 `https://script.google.com/macros/s/.../exec` 주소를 복사합니다. `/dev` 주소는 사용하지 마세요.
7. `config.js`의 `appsScriptUrl`에 붙여 넣습니다. 브랜드 이름, 인스타그램, 자사몰 주소(`storeUrl`)도 설정합니다.
8. 테스트 1건을 완료한 뒤 구글시트 `응답_v2` 탭에 한 행이 생성되는지 확인합니다. 기존 연결이 있다면 수정한 `Code.gs`를 반영하고 `setupSheet` 실행 후 웹 앱 배포를 업데이트합니다. 기존 `응답` 탭은 그대로 보존됩니다.

> Apps Script는 공개 쓰기 엔드포인트입니다. 악의적인 자동 요청, Apps Script 호출 제한, 스팸 입력 등 가능성이 있으므로 행사 기간에 모니터링해야 합니다. 인증된 참가자만 쓸 수 있는 강력한 보안이 필요한 운영에는 별도 백엔드를 권합니다.

## 2. GitHub Pages 배포

1. GitHub에서 **새 Public 저장소**(예: `dogs-mbti`)를 생성합니다.
2. 이 폴더의 `index.html`, `styles.css`, `theme.css`, `app.js`, `config.js`와 `asset` 폴더를 저장소 **최상위(root)**에 업로드합니다. `Code.gs`와 README도 함께 업로드해도 되지만, `Code.gs`에는 비밀정보를 넣지 마세요.
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
4. Branch `main`, Folder `/(root)`를 지정하고 **Save**합니다.
5. `https://깃허브아이디.github.io/dogs-mbti/` 형태의 주소에서 테스트합니다. 이 URL을 QR코드로 변환해 부스에 부착합니다.

## 3. 현장 운영 주의사항
- 보호자의 시식 적합성 확인 후 급여; 거부, 긴장, 식이 제한이 있으면 시식하지 않음 선택
- 제품 7종 모두가 어떤 강아지에게나 적합하다는 뜻이 아님
- 실제 선택과 보호자 선택은 별도 기록하므로 동일한 기호성 데이터로 분석하지 않기
- 결과의 성향 수치는 설명용이며 과학적 진단 정확도가 아님
- 배포 전 개인정보 안내의 **운영 주체, 문의처, 보유 기간, 삭제 방법**을 구체화하기
- 구글시트 공유 설정을 비공개로 유지. URL을 아는 사람에게 편집 권한을 주지 않기
- 기기/브라우저에 따라 직접 이미지 공유를 지원하지 않을 수 있어 PNG 저장을 기본 경로로 제공

## 자체 점검
- 성향 4문항 + 간식 2문항 모두 응답 → 4개 유형 중 하나 결과
- 간식 선호 응답을 바꿔도 성향 결과가 바뀌지 않음
- 7개 제품별 결과 문구 변경
- '시식하지 않음' 선택 시 결과 표시
- Apps Script URL 미설정 → 저장 요청 없이 결과 확인
- Apps Script URL 설정 → 결과 확인 시 저장 성공 메시지 및 시트 1행 기록
- PNG 다운로드 / Android·iOS 공유 지원 여부 현장 기기로 점검

## 로고 파일

- `asset/megazoo-logo.png`: 제공받은 메가주 로고 원본
- `asset/yeet-logo.png`: 제공받은 YEET 브랜드 로고 원본
- 헤더와 결과 카드에서 각각의 로고를 표시합니다.
- 설문은 평소 탐색·활동 성향을 기준으로 하며, 간식을 선택하거나 시식하지 않음을 선택한 뒤 결과를 확인합니다. 기존 간식 설문 데이터와 새 성향 설문 데이터는 별도로 관리하세요. 새 설문의 Apps Script 수신 항목은 `activity`이며 시트 열 이름은 `활동성평균`입니다.

## 간식 선호 데이터

- 설문 버전: `temperament-treat-v2`. 표시 순서와 별개로 저장 배열의 Q1~Q4는 성향, Q5~Q6는 간식 선호입니다. 화면 순서를 섞어도 저장 열과 점수 계산은 유지됩니다.
- Q5 `간식식감선호`: 1은 부드럽고 쉽게 씹힘, 5는 쫄깃하고 씹는 맛이 있음.
- Q6 `간식원료선호`: 1은 육류(닭·오리·소), 5는 생선(연어·명태).
- 두 항목 모두 3은 양쪽이 비슷함. 모든 문항은 필수이며 `null` 응답은 저장하지 않습니다.
- 현장 시식 선택과 평소 선호를 별도 열에 기록합니다. 기존 6문항 성향 설문과 섞이지 않게 `응답_v2` 탭에 저장합니다.
